# Finding the right guide when names are similar

Guide names are not unique. It's common for an account to have several guides with similar or overlapping names (e.g. two different "onboarding" guides for different apps or audiences) — each has its own unique guide ID, status, segment, and app assignment.

Because these can have completely different statuses and behavior, a request that names only a general topic ("my onboarding guide") rather than an exact guide is ambiguous whenever more than one guide matches. Diagnosing the wrong guide produces an answer that is accurate for a guide the customer didn't mean, which is worse than asking — it wastes their time and can make a working guide look broken (or a broken one look fine). When more than one guide plausibly matches, confirm which one before running any further checks.
