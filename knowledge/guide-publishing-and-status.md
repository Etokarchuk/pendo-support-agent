# Guide publishing and status

A guide has two relevant states:

- **Draft** — the guide exists and can be previewed by admins in the guide editor, but it is never shown to real visitors. Nothing else about the guide (segment, targeting, content) matters until it is published.
- **Published** — the guide is live and will be shown to any visitor who is eligible under its assigned segment, subject to display frequency rules and the visitor's app having the install snippet active.

**Publishing is a manual, explicit action** taken by an account admin from the guide editor. There is no auto-publish, and saving changes to a draft does not publish it. If a guide was previously published and then edited, the edits apply immediately to the live guide — editing does not create a new draft or require re-publishing.

**Common confusion:** a guide the admin considers "done" is often still in draft, because the last step (clicking Publish) is separate from finishing the content. If a customer reports "nobody sees my guide" and the guide is in draft, that is very often the whole explanation — check status before checking anything else.
