# Account roles and permissions

Guide content, segment assignment, publish status, and scheduling can only be changed in-app by a user with an Admin or Editor role on the account, from the guide editor. There is no supported way for anyone else — including support — to change a live guide's segment, republish it, or edit its content on the customer's behalf; doing so would silently change what the customer's own admins see when they open the guide editor, and would bypass their own change history and review process.

Support and any assistant acting on the account's behalf can **diagnose** configuration (read guide, segment, and install status) and **recommend** a specific settings change, but cannot **perform** that change. The customer's own admin must make the edit in the guide editor.
